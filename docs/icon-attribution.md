# Icon attribution

## General icons

The application uses 50 selected components from lucide-react 0.468.x, licensed
under ISC. See the [Lucide license](https://github.com/lucide-icons/lucide/blob/main/LICENSE).
The full catalog is not loaded dynamically.

## Provider icons

The provider SVG paths, names and colors were extracted from
[Simple Icons 16.31.0](https://github.com/simple-icons/simple-icons/tree/16.31.0),
except OpenAI and AWS, which use [Simple Icons 8.1.0](https://github.com/simple-icons/simple-icons/tree/8.1.0).
The source archive is the official simple-icons npm release; only selected paths
are vendored in src/client/obligation-brand-icons.ts. The package is not a runtime dependency.

The collection is published under [CC0-1.0](https://github.com/simple-icons/simple-icons/blob/16.31.0/LICENSE.md).
Brand rights remain with their respective owners; see the
[upstream disclaimer](https://github.com/simple-icons/simple-icons/blob/16.31.0/DISCLAIMER.md).
Icons identify services selected by users and do not imply affiliation. The
following source and guideline links are retained from the upstream catalog.

## Rendering

The picker contains 50 general icons and 12 provider icons in each of Music, Film
and TV, and Services. SVG paths render inline without remote logo requests or
HTML injection. Financial records store only a stable icon ID; unknown IDs use
a neutral house fallback. Actual bundle contribution depends on shared imports.
